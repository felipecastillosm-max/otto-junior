# Otto Junior

PWA de apoyo al asistente de bus: lista de pasajeros, aviso de paradero por GPS y reporte automático a WhatsApp. Diseñada para funcionar sin conexión a internet.

## Wireframe (`public/`)

Maqueta clickeable de las 3 pantallas principales: pasajeros, paradero, reporte. Es solo HTML/CSS estático, sin backend todavía.

## Cómo verlo en local (VS Code)

1. Instala la extensión **Live Server** en VS Code (si no la tienes).
2. Click derecho sobre `public/index.html` → "Open with Live Server".
3. Se abre en el navegador y puedes navegar entre las 3 pantallas.

Alternativa sin extensión, desde la terminal:

```
npx serve public
```

y abres la URL que te muestre (ej: http://localhost:3000).
